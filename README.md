# AWS Static Website Hosting Infrastructure

Hosted a static website on AWS using Amazon S3 Static Website Hosting.

## Project Overview
This project demonstrates how to deploy a static website manually using AWS S3.

The website is publicly accessible through an S3 website endpoint.

## AWS Services Used
- Amazon S3
- Static Website Hosting
- Bucket Policy

## Features
- Static website hosting
- Public access configuration
- Custom index page
- Error page support

## Project Structure
```bash
aws-static-website/
├── index.html
└── README.md
```

## Deployment Steps
1. Created S3 bucket
2. Uploaded website files
3. Disabled block public access
4. Enabled static website hosting
5. Added bucket policy
6. Accessed live website URL
